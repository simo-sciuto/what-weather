# ROADMAP

Direction, not tasks (tasks live in BOARD.md). Only the user sets this; the phases below are a proposal from the bootstrap audit, to be edited.

## Phase 1: Foundation (done)
Provider abstraction, normalized WeatherData, timeline, outlook sentence, caching, mock provider, unit and e2e tests.

## Phase 2: Product refinement
Trustworthy data semantics (air quality, measured vs interpolated, min/max), information hierarchy, forecast and location experience.

## Phase 3: Portfolio quality
Accessibility, performance, PWA, mobile refinement, error and empty states.

## Phase 4: Polish
Motion, micro-interactions, final QA.
